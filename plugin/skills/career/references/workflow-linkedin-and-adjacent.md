# LinkedIn Profile & Adjacent Outputs (Workflow 7)

**Purpose:** Reuse the master docs to produce a LinkedIn profile, a cover letter,
STAR interview prep, or cold outreach — same evidence, same accuracy and
anti-AI-slop rules, different medium. See `references/linkedin-and-adjacent.md`
for the format specs and character limits.

1. **Confirm the deliverable** (LinkedIn profile, cover letter, STAR stories,
   outreach) and the target role if there is one.
2. **Draft from evidence** — pull from master docs (or an already-tailored
   resume). LinkedIn is more conversational and search-driven; front-load target
   job-title keywords in the headline and About. Honor confidentiality.
3. **Critique pass** — apply the writing standard and mandatory rewrite from
   `references/writing-style-and-verbs.md` before presenting.
4. **Save** where the user wants (e.g. a stable `linkedin.md`, or the job folder
   for a role-specific cover letter).
