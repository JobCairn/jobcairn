# Writing Style & Strong Verbs

Use when drafting or rewriting bullets, summaries, or any candidate-facing prose
(Workflows 1, 2, 4c, 7). The goal is writing that sounds like a sharp person, not
a language model.

## SAR framing

Structure each accomplishment as **Situation → Action → Result**, then compress
into a bullet carrying **Action + Scope + Method + Outcome**:

- Situation: what was the challenge/context?
- Action: what did *you* do (distinguish solo ownership from team work)?
- Result: what changed — quantified where the evidence supports it?

**Example**
- Interview notes: "Our releases kept breaking. I set up a new CI pipeline that
  ran service tests in parallel. Deploys got a lot faster."
- Bullet: "Cut deployment time 45% across 12 microservices by building a
  parallelized CI pipeline with automated test gating."

## Write like a person, not an AI (target Flesch reading ease > 90)

This is what separates a resume that lands from one that reads as generated.
Aim for short, plain, confident sentences.

- **One idea per sentence.** If a sentence uses "and" to bolt two unrelated
  clauses together, split it.
- **No em-dashes.** Use commas, periods, colons, semicolons, or parentheses.
- **No preamble clauses.** Bad: "Leveraging deep expertise in marketplace
  dynamics, led…". Good: "Led…".
- **No stacked adjectives.** Bad: "cross-functional, data-driven,
  customer-centric approach." Pick the one that matters and show it concretely.
- **Kill filler phrases:** "demonstrating ability to", "showcasing expertise in",
  "with a track record of", "responsible for", "helped with", "spanning",
  "leveraging", "utilizing".
- **No compound-noun piles.** "AI-driven product opportunity identification and
  execution" → "Built an AI product from idea to production."
- **Summaries: 2–3 short sentences, each under ~20 words.** No run-ons chaining
  capabilities with commas and "and".
- **Vary structure.** Not every bullet should follow the identical pattern.
- **Active voice, strong verbs**, one lead verb per bullet.

## Mandatory critique-and-rewrite pass (before showing anything)

AI-sounding phrasing creeps in on the first draft. Always do a second pass,
line by line, and fix it *before* presenting to the user. Ask of each line:

1. **Doing too much?** More than one comma-separated clause → split it.
2. **Would a real person say this out loud?** If it reads like a LinkedIn post or
   a chatbot reply, rewrite it. If a sentence takes more than one breath to read
   aloud, it's too long.
3. **Any filler?** Cut anything that adds no information.
4. **Stacked buzzwords?** Replace with one concrete example.
5. **Summary under control?** ≤3 sentences, each <20 words, ≤2 things per sentence.

Patterns to hunt and kill:
- "I combine X with Y, Z, and the W needed to…" → separate statements.
- "…demonstrating [abstract quality]" → delete or state the actual result.
- "…spanning [long list]" → keep the 1–2 that matter.
- "Led [action], [action], and [action] across [scope]" → one action per bullet.
- Gerund tails: "…delivering X while maintaining Y" → two sentences.
- Any bullet over two lines is usually doing too much — split it.

## Strong verbs by function

| Function | Verbs |
|----------|-------|
| Leadership | Led, Directed, Managed, Drove, Spearheaded, Orchestrated |
| Creation | Built, Designed, Developed, Launched, Established, Architected |
| Growth | Grew, Increased, Expanded, Scaled, Accelerated, Doubled |
| Improvement | Improved, Optimized, Streamlined, Transformed, Modernized |
| Delivery | Delivered, Shipped, Completed, Executed, Achieved, Exceeded |
| Analysis | Analyzed, Identified, Evaluated, Assessed, Researched |
| Collaboration | Partnered, Coordinated, Collaborated, Unified, Aligned |

Avoid repeating the same lead verb within a role; vary by function above.

## Level-matching (position for the target seniority)

Emphasis should match the level of the role being targeted — reframe what's
already true, never invent scope.

- **Executive (VP/C-level):** strategy, P&L, board interaction, org building,
  cross-functional leadership.
- **Director:** program ownership, team management, operational excellence,
  stakeholder management.
- **IC:** hands-on execution, technical depth, individual contributions,
  collaboration.

A VP applying to a Director role leans on strategic impact; a Director reaching
for VP emphasizes scope and leadership growth. Match honestly.

## Strict accuracy (never fabricate to fit)

- Use only what's on the resume or in the master docs / profile.
- Never assume business model (B2B vs B2C), revenue type, or company stage unless
  stated. Never infer scope beyond what's written (e.g. don't upgrade "revenue
  targets" to "P&L ownership"). Never add partnerships, skills, or responsibilities
  that aren't documented.
- When ambiguous, use conservative language or omit the detail.
- Don't change titles or dates. Don't drop roles (gaps look suspicious).
- Reframe what *is* there; never invent what *isn't*.
