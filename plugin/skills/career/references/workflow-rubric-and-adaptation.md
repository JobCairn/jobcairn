# Rubric Development & Resume-Adaptation Evaluation (Workflow 3)

**Purpose:** Create or refine scoring rubrics, or evaluate how well a resume
adaptation matches a role.

1. **Clarify the mode:** building/refining a rubric, vs. evaluating an existing
   resume/adaptation against current rubrics.
2. **Rubric development:** Read the existing rubrics first (for structure and
   voice), then propose or refine criteria and weights *in the same style* so the
   set stays coherent. Explain the reasoning behind each weight — a rubric the
   user understands is one they'll actually trust and maintain.
3. **Adaptation evaluation:** Load the resume and target job. Score with Ideal Job
   Match and Interview Odds. Check the resume against the suggested revisions (if
   any exist) and against requirement coverage. List strong alignment and
   risks/gaps, then suggest improvements.

**Deliver:** a rubric draft *or* an evaluation summary — scores, strengths, risks,
concrete next steps.
